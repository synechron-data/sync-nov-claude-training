# Implementation Plan: Task Priority

**Branch**: `001-task-priority` | **Date**: 2026-11-18 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `/specs/001-task-priority/spec.md`

## Summary

Add a three-level priority (Low, Medium, High) to tasks, defaulting to Medium, and let users filter
the task list by priority and completion status and opt in to sorting by priority. The backend adds a
`priority` field to the `Task` entity and request records, and extends the existing `GET /api/tasks`
with optional `priority`, `completed`, `sort` and `order` query parameters, applied on top of the
existing owner-scoped query. The frontend adds a priority picker to the create/edit UI, filter and
sort controls, and passes them through `TaskService`. Everything is additive: omitting the new
request field or query parameters yields exactly today's behaviour and response shape (plus one new
`priority` property).

## Technical Context

**Language/Version**: Java 17 (backend); TypeScript, strict mode (frontend)

**Primary Dependencies**: Spring Boot 3.2.5, Spring Web, Spring Data JPA, Spring Security 6, Jackson (all existing); Angular 17.3 standalone components, RxJS 7.8. No new dependencies.

**Storage**: H2 via Spring Boot defaults. `backend/pom.xml` includes H2 and no `application.properties` exists, so the schema is generated by Hibernate at startup; there is no migration tool.

**Testing**: JUnit 5 + Mockito + AssertJ + MockMvc (backend, mirrored under `src/test/java`); Jasmine/Karma via `ng test` (frontend)

**Target Platform**: Spring Boot web service plus Angular single-page app in a browser

**Project Type**: Web application (`backend/` + `frontend/`)

**Performance Goals**: A filter or sort update visible in under 1 second for 500 tasks (spec SC-006)

**Constraints**: Additive API only (existing fields and endpoints unchanged); owner scoping on every read and write; no new dependencies; invalid input returns 400 JSON via `GlobalExceptionHandler`, never 500

**Scale/Scope**: Per-user task lists in the hundreds; five source files per side touched
